# Каталог товаров для StyleMate AI

Текущий ручной каталог в `script.js` нужен только для прототипа. Для нормальной версии сервис должен работать так:

1. Берем список брендов и категорий из `data/brand-sources.json`.
2. Backend запускает `tools/catalog-sync.mjs`.
3. Скрипт собирает конкретные карточки товаров: название, бренд, категория, цена, артикул, ссылка, изображение, наличие.
4. Результат сохраняется в `data/live-catalog.json`.
5. Стилистический алгоритм выбирает вещи только из `live-catalog.json`.
6. После выбора вещей image-generation получает не абстрактный образ, а точные товары с картинками и ссылками.

## Запуск синхронизации

```bash
cd ai-online-stylist
CATALOG_SYNC_LIMIT=24 node tools/catalog-sync.mjs
```

`CATALOG_SYNC_LIMIT` ограничивает количество карточек, которые скрипт берет из каждой категории. Для теста достаточно 12-24, для продакшена можно увеличить.

## Важно

Некоторые сайты могут отдавать пустую страницу, капчу, динамический HTML или блокировать автоматический сбор. Для таких брендов в `brand-sources.json` стоит статус `needs-feed-or-parser`. Это значит, что для стабильной работы нужен отдельный adapter, feed или серверный scraper с cookies/proxy.

Нельзя делать вид, что ссылка подходит, если товар визуально другой. Поэтому генерация образа должна строиться только после того, как товар уже есть в каталоге с картинкой карточки товара.
